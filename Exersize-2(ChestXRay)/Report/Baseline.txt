# Baseline CNN Notes

## Objective

Develop a CNN-based classifier for Chest X-Ray images to classify:

* NORMAL
* PNEUMONIA

using MobileNet architecture.

---

## Original Implementation Reference

Original implementation obtained from:

Kaggle Medical Image Classification notebook.

Architecture used:

* MobileNet
* No pretrained weights
* Binary classification

---

## Major Modifications Made

### 1. Reproducibility Improvements

Added fixed seeds for:

* NumPy
* Python random
* TensorFlow

Reason:

To reduce variation between multiple runs.

---

### 2. Dataset Pipeline Modifications

Modified dataset handling for:

* Stable train/test/validation split
* Controlled shuffling
* Consistent preprocessing

Reason:

To maintain identical dataset splits across experiments.

---

### 3. Generator / Training Fixes

Modified training procedure to avoid:

* Generator exhaustion
* Interrupted training behavior
* Inconsistent epoch behavior

Reason:

Training instability was observed during initial implementation.

---

### 4. Model Saving Improvements

Added:

* Model checkpointing
* Best validation loss saving

Reason:

Best performing model should be evaluated instead of final epoch model.

---

### 5. Evaluation Pipeline Added

Added:

* Accuracy
* Precision
* Sensitivity
* Specificity
* F1 Score
* ROC Curve
* AUC
* Confusion Matrix

Reason:

Assignment requires detailed evaluation metrics.

---

# Observations

* Training became more stable after pipeline modifications.
* Validation behavior remained somewhat unstable due to dataset size imbalance.
* High precision indicates strong confidence in positive predictions.
* Lower sensitivity suggests some pneumonia cases remain missed.
* MobileNet provides reasonable performance even without pretrained weights.
