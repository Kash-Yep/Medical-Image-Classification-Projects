# Exercise-1: Brain Tumor Detection using SVM + PCA

## Project Description

The objective of this project is to classify MRI brain scans into:

- No Tumor
- Pituitary Tumor
- Glioma Tumor
- Meningioma Tumor

Method used:

- Image preprocessing
- Normalization
- PCA dimensionality reduction
- SVM classification
